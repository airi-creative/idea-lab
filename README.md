# Idea Lab

A loose little lab for ideas, demos, skills, experiments, and things I build with Codex.

Some projects here are polished. Some are half-formed sparks. Everything is allowed to start messy.

## Spaces

- `inbox/` - quick ideas before they need a category
- `demos/` - small runnable prototypes
- `skills/` - Codex skills, workflows, and reusable prompts
- `experiments/` - tests, explorations, and weird little trials
- `notes/` - ideas, plans, and build logs
